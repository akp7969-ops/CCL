Ploop

Scientific Name:

Underwater Snake

Discovered by / at:

Ava Park, 10/15/2026

Family:

Ploop unfortunately has no family because they all got caught by fisherman.

Habitat:

Deep underwater because it likes the darkness and the cool temperature.

Appearance:

Ploop is an underwater snake. The skin color is cyan because I wanted to make the creature seem like it was glowing underwater so that it can be seen easily. Ploop has no eyes because Ploop is blind and so I also intentionally made the circles (Ploop's food) bright in color so that Ploop can at least see something glowing.

Key Characteristics:

  • Blind.
  • Glows.
  • Likes eating.

What we know so far about [ NAME OF YOUR CREATURE ]? Ploop is an underwater snake that is blind and glows. It likes to eat small glowing circles which represent little fish that are floating around in the water. It is a very independent creature and likes to be alone. It is also very curious and likes to explore its surroundings. However Ploop has its dietary restriction: Ploop can only eat small glowing circles that are yellow and cannot eat any of the red circles. Here, I chose yellow to represent vitamin D because Ploop barely gets any sunlight. Ploop doesn't like warm waters, so it stays deep underwater where sunlight barely reaches. It is also very fast and can swim very quickly.
Guidelines for human interaction with this creature Humans usually catch underwater snakes like Ploop to keep as pets. But it is important to not catch Ploop. Ploop is a very independent creature and does not like to be touched or held. It is also very fast and can swim away quickly if it feels threatened. It is important to not feed Ploop any red circles because it can make Ploop sick. It is also important to not touch Ploop because it can get scared and swim away quickly.
